## Documentation

Debug View streams the tracking requests a site received during the last 30 minutes,
live, under **Administration → Diagnostics → Debug View**.

Every hit (pageview, event, goal conversion, download, outlink, site search,
ecommerce order/cart, content interaction) appears in a reverse-chronological
stream within seconds of arriving. The minutes rail on the left summarises the
last 30 minutes; clicking a hit opens a details pane listing all hit parameters
("Parameters" tab) and the visit/user context ("Visit" tab).

Data comes from the Live plugin's visits log. The page is only available while
the Live plugin is activated and the Visits Log is enabled, and users only ever
see sites they have at least view access to.
